# Quick Start

### Avvio dell'applicazione rust

Dentro la cartella `rustix` dare questo comando:
```bash
cargo run -p app
```

### Avvio del frontend

N.B. Se è la prima volta, entro la cartella `rustix/frontend` dare questo comando: `npm install`, che scaricherà tutto il necessario

Dentro la cartella `rustix/frontend` dare questo comando:
```bash
npm run dev
```
Questo avvia la webapp Next.js, visualizzabile all'url: `http://localhost:3000/`
